    What This App Is
    A portfolio view for multiple project boards. You can import projects, focus one project, and manage tasks directly from the same screen.

    Getting Started

    • Use New Project to create a project file and add it to the portfolio.
    • Use Import Projects to load one or more existing .json files.
    • You can also drag project files into the app to import them.

    Navigation & Filters

    • Use the project chips to switch between All projects and a single project.
    • Search filters by task name.
    • Archive, Sort, Priority, and Effort controls update the visible cards.

    Working With Tasks

    • Click a card to open task details.
    • Use the card actions to edit, archive, or delete a task.
    • When a writable project is selected, each column shows + Add Task.
    • Drag cards between columns to change status. Moves auto-save for writable projects.

    Read-Only Projects

    • Projects imported without a file handle are marked (Read-only) in the chip.
    • You can still open and inspect tasks.
    • Edit/archive/delete actions are disabled until the project is opened with a writable file handle.
    Quick shortcuts: ? opens this shortcut list, / focuses search, I imports projects, and Esc closes modals.
