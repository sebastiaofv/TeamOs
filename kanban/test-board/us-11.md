# US-11 · Dados mestres do projeto

Usar uma **cópia** de `us-11.board.json`; contém apenas dados fictícios e usa o esquema legado v1 de propósito. Importar pelo seletor de ficheiros para permitir gravação; arrastar o ficheiro para testar só de leitura. Usar `npm run dev` em `kanban/` num browser com File System Access API.

## Migração e edição

1. Importar o ficheiro e abrir o ícone de settings junto ao nome no topo. Esperado: nome existente, descrição vazia, estado **Por definir**, membros Ana e Rui (não duplicar `ana`), tag `demo`. Abertura não escreve no ficheiro.
2. Abrir outro projeto e, mantendo-o selecionado, abrir as definições deste projeto. A seleção não muda; o ícone só existe no topo, não nos badges dos cartões nem em Todos.
3. Alterar nome, descrição e estado; Cancelar. Repetir com ×, Escape e clique fora. Reabrir: os valores originais mantêm-se e o foco regressa ao ícone.
4. Guardar nome `Projeto de demonstração`, descrição livre, estado Ativo e nome de membro `Ana Silva`. Esperado: nome no seletor atualizado; participantes das duas tarefas (incluindo a arquivada) passam a Ana Silva. IDs das tarefas e roadmap mantêm-se; responsável continua vazio porque não foi inventado pela migração.
5. Inspecionar o JSON gravado: esquema base atual, `extensions.project.version = 1`, ID de projeto, membros com IDs, `assigneeIds`/`responsibleId` nas tarefas. Renomear a cópia do ficheiro no sistema e reabrir: o ID persistido não muda.
6. Tentar nome de projeto só com espaços ou membro vazio; esperado: erro e rascunho conservado. Tentar renomear Rui para ` ANA SILVA `: rejeitar duplicado, sem fundir pessoas.
7. Adicionar membro livre, guardar, reabrir e removê-lo: permitido. Remover Ana Silva: bloqueado enquanto houver atribuições, incluindo arquivadas.

## Histórico, estado e leitura

1. Na timeline, selecionar a baseline anterior à alteração. Abrir settings: valores anteriores, formulário só de leitura. Restaurar essa versão: recupera nome/descrição/membros/atribuições anteriores, mantendo o ID do projeto e o histórico.
2. Escolher os cinco estados, incluindo Concluído/Arquivado com uma tarefa em curso: não bloqueia, não oculta o projeto nem altera/arquiva tarefas. É possível continuar a editar e voltar a Ativo.
3. Abrir por arrastar: settings consultáveis, campos desativados e sem Guardar; nenhuma gravação.
4. Criar um projeto novo: só exige nome, começa Planeado, descrição e membros vazios. As tags predefinidas pertencem à US-21 e podem ser removidas enquanto não utilizadas.
5. Simular erro de escrita/permissões do ficheiro: alterações aplicadas continuam em memória, seletor indica falha e permite nova tentativa. Deteção de alterações externas/conflitos segue o fluxo existente; não sobrescrever silenciosamente um rascunho obsoleto.
6. Repetir navegação por teclado e em PT/EN, modo claro/escuro. Verificar rótulos, foco, scroll e erros legíveis.
