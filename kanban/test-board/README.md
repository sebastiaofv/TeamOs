# Projeto de exemplo TeamOS

Esta pasta contém **um único projeto de exemplo**: [TeamOS — Desenvolvimento da Aplicação](teamos-development/README.md).

No TeamOS de `main`, escolher **Import Projects** e selecionar esta pasta ou `teamos-development/`. Copiar o projeto antes de explorar: as alterações são guardadas automaticamente nos ficheiros selecionados.

O exemplo combina evidência real do desenvolvimento com reconstruções e interações identificadas como **(fictício)**. Inclui trabalho concluído, em execução, em teste e por planear, desde junho a novembro de 2026, com planeamento futuro até dezembro.

Os antigos boards específicos de cada funcionalidade foram retirados desta pasta. As fixtures necessárias à regressão automática ficam em `tests/fixtures/manual/`; não são projetos de demonstração adicionais.
